## Binary Number Representation

### 1. Decimal 75 to Binary

Repeatedly divide the decimal number by 2 and record
the remainder.

| Division | Quotient | Remainder |
|---|---:|---:|
| 75 / 2 | 37 | 1 |
| 37 / 2 | 18 | 1 |
| 18 / 2 | 9 | 0 |
| 9 / 2 | 4 | 1 |
| 4 / 2 | 2 | 0 |
| 2 / 2 | 1 | 0 |
| 1 / 2 | 0 | 1 |

Reading the remainders from bottom to top:

**75 (decimal) = 1001011 (binary)**

### 2. Binary 110101 to Decimal

Using the positional weight method:

110101 (binary)

= (1 × 2^5) + (1 × 2^4) + (0 × 2^3)
  + (1 × 2^2) + (0 × 2^1) + (1 × 2^0)

= 32 + 16 + 0 + 4 + 0 + 1

**= 53 (decimal)**

### 3. Why Computers Use Binary

Computers use binary because their electronic circuits
can reliably represent two states, ON (1) and OFF (0),
making data processing and storage efficient.
